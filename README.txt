REX'S DINER WEBSITE
===================

Failid:
- index.html   -> veebilehe sisu
- styles.css   -> kujundus
- script.js    -> mobiilimenüü ja väike JavaScript

KUIDAS ARVUTIS VAADATA
1. Paki ZIP lahti.
2. Ava index.html topeltklõpsuga.

KUIDAS TASUTA INTERNETTI PANNA GITHUB PAGESIGA
1. Tee tasuta GitHub konto.
2. Loo uus public repository, näiteks: rexs-diner
3. Lae index.html, styles.css ja script.js repository juurkausta.
4. Ava repository Settings > Pages.
5. Source: Deploy from a branch.
6. Branch: main / root.
7. Save.

GitHub annab sulle tasuta aadressi kujul:
https://SINUNIMI.github.io/rexs-diner/

MÄRKUS
Kodulehel pole hetkel eraldi logo- või toidupilte, nii et see töötab kohe ilma lisafailideta.
Hiljem saab lisada Rex's Dineri päris logo, menüü pildid, Google Formsi tööavalduse lingi ja muud detailid.
